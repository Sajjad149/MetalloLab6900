# MetalloLab — نسخه آموزشی پایه

## پیش‌نیاز
Android Studio پایدار، JDK 17 و Android SDK Platform 35.

## ساخت APK
1. ZIP را استخراج کنید.
2. پوشه پروژه را در Android Studio باز کنید.
3. منتظر پایان Gradle Sync بمانید.
4. از منوی Build گزینه Build APK(s) را بزنید.
5. APK تستی معمولاً در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## تنظیمات
- Kotlin + Jetpack Compose
- minSdk 23
- targetSdk 35
- ABI فیلترشده: arm64-v8a

## توجه
این سورس نسخه پایه آموزشی است و در این محیط کامپایل یا روی دستگاه واقعی تست نشده است. محتوای اطلس فعلاً متنی است؛ تصاویر دارای مجوز، ذخیره پیشرفت، بانک سوال گسترده، Room، PDF و تحلیل تصویر در مراحل بعد اضافه می‌شوند. برای انتشار، نسخه SDK و الزامات روز فروشگاه را مجدداً بررسی و APK/AAB را با کلید امضای اختصاصی امضا کنید.
